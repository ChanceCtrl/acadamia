#### Examples
$\{0\}$ is a set with 1 element, the symbol 0. Sets can be within sets and elements within a set are unique, so $\{0, 1, 1, 2, 3, 3, 3\}$ is equal to the set $\{0, 1, 2, 3\}$ and $0 \neq \{0\}$ as 0 is a symbol, not a set, you could however say that $0\in\{0\}$

### Subset $\subset$
In mathematics, a [[Set Theory Defs#Set|set]] $A$ is a **subset** of a set $B$ if and only if all [[Set Theory Defs#Element|elements]] of $A$ are also elements of $B$; $B$ is then a **superset** of $A$. It is possible for $A$ and $B$ to be equal; if they are unequal and all elements of A are contained within B, then $A$ is a **proper subset** ($\underline{\subset}$) of $B$.

### String
Given a finite [[Set Theory Defs#Set|set]] called $A$, you put together a list of elements from it with a given length $n$ with no delimiter (parens, commas brackets etc). You could say a string is a finite list of finite characters, and that a _null-string_ is a list of finite characters with length 0.
### What is $\in$
$\in$ is the symbol for "contains", it states the the thing in front of it, is within the thing behind it, for example $1$ is in the set $\{1, 2, 3, 4\}$ so you could write $$1 \in \{1,2,3,4\}$$and that would be a true statement.
